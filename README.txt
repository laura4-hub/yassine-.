LEGEND OF YASSINE — COMPLETE WEBSITE

FILES
- index.html : website structure
- style.css  : design, layout and animations
- script.js  : game logic, missions, music and birthday surprise

REQUIRED MEDIA FILES
Upload these three files into the SAME folder as index.html:
- videoplayback.weba   (game soundtrack)
- birthday-song.mp3    (song on the final cake page)
- cat.jfif             (cat photo revealed after the red-panda game)

IMPORTANT
The filenames must match exactly, including spelling and extension.
Do not put the media files in another folder.

PUBLISH WITH GITHUB PAGES
1. Create a new GitHub repository.
2. Upload index.html, style.css and script.js.
3. Upload the three media files listed above into the repository root.
4. Open Settings > Pages.
5. Under Build and deployment, select Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait for GitHub Pages to publish the site.

The site uses Google Fonts from the internet. The game itself is plain HTML, CSS and JavaScript.
